The site for the Synology Download Assistant browser extension.

## Contents

- Pages for features, downloads, community and contact.
- A translations system that tracks how complete each language is.
- A download counter.

The extension itself is in
[synology-download-assistance-chrome-extension](https://github.com/dmzoneill/synology-download-assistance-chrome-extension).

## Tech

- PHP and MySQL
- CSS and JavaScript

## Running

Serve the folder with a web server that has PHP, and a MySQL database where the
code uses one (see `connect.php` or `db_mysql.php`).
